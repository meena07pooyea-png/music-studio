ออกแบบ UX/UI สำหรับหน้า Admin ของแอปพลิเคชัน “Music Studio” ระบบเช่าห้องซ้อมดนตรี โดยสร้างเป็น Web Admin Dashboard ที่ใช้งานง่าย ทันสมัย และเป็นระบบ เหมาะสำหรับผู้ดูแลสตูดิโอ

ออกแบบให้ Admin สามารถจัดการข้อมูลห้องซ้อม การจอง สถานะห้อง ลูกค้า และการชำระเงินได้จากหน้า Admin โดยไม่ต้องกลับไปยังหน้าของ User

## 1. Admin Login

สร้างหน้าเข้าสู่ระบบสำหรับ Admin โดยมี

* Logo และชื่อ Music Studio
* ช่อง Email / Username
* ช่อง Password
* ปุ่ม Login
* Remember me
* Forgot Password
* แจ้งเตือนเมื่อ Login ไม่สำเร็จ
* หลัง Login สำเร็จให้เข้าสู่ Admin Dashboard

## 2. Admin Dashboard

สร้างหน้า Dashboard เป็นหน้าแรกหลังจาก Admin Login

ด้านบนแสดง Summary Cards ได้แก่

* จำนวนห้องทั้งหมด
* ห้องว่าง
* ห้องที่กำลังใช้งาน
* ห้องที่ถูกจอง
* จำนวนการจองรอยืนยัน
* จำนวนการชำระเงินรอตรวจสอบ
* รายได้รวม

แสดงข้อมูลในรูปแบบ Card ที่ดูง่ายและใช้สีแยกสถานะ

เพิ่มส่วน

* ตารางการจองล่าสุด
* รายการชำระเงินล่าสุด
* ห้องที่กำลังถูกใช้งาน
* การจองที่รอ Admin ยืนยัน
* การชำระเงินที่รอตรวจสอบ

## 3. Sidebar Navigation

สร้าง Sidebar สำหรับ Admin โดยมีเมนู

* Dashboard
* จัดการห้องซ้อม

* ปฏิทินการจอง

* Logout

Sidebar ต้องสามารถย่อ/ขยายได้ และแสดง Active Menu อย่างชัดเจน

## 19. Prototype Interaction

สร้าง Prototype ให้สามารถกดใช้งานได้จริงระหว่างหน้าต่างๆ

เช่น
Login → Dashboard
Dashboard → Booking
Booking → Booking Detail
Booking Detail → Payment
Payment → Verify Payment
Verify Payment → Confirm Booking
Confirm Booking → Room Status
Room Status → Room Detail
Room Detail → Edit Room

เพิ่ม Modal สำหรับ

* ยืนยันการจอง
* ยืนยันการชำระเงิน
* ปฏิเสธการจอง
* ลบห้อง
* ยกเลิกการจอง

เป้าหมายคือสร้าง Admin Dashboard ที่สามารถใช้จัดการระบบเช่าห้องซ้อมดนตรีได้ครบตั้งแต่ “จัดการห้อง → รับการจอง → ตรวจสอบเงิน → ยืนยันการจอง → ติดตามสถานะห้อง → ดูรายงาน” ในระบบเดียว
